Settings

Every panel here is optional — nothing needs changing to use the app. Click Save at the bottom after any change.

Roaster safety

Limits on Heater/Fan/Drum, and the emergency fan level. See Control & Safety for the full explanation.

Temperature Unit

Celsius or Fahrenheit, applied everywhere: live readouts, the chart, history, downloads (.alog, JSON, CSV, Excel, PDF), and every threshold/setpoint field you type into (Dry End/FC Start, Burner SV range, alarm rule thresholds, device profile setpoint ranges, Hold Target). Storage and the API always stay Celsius underneath; only what you see and type converts. For a Direct Modbus connection, this setting also decides whether the controller's own raw register values are treated as Fahrenheit and converted, so pick the unit that actually matches your controller's own display.

Big Readout Panel & Small Readout

Pick which live values show in these two optional panels next to the live chart. Independent of each other (a value can be in one, both, or neither), but share the same colors.

Controls

Arrange the vertical control sliders (Drum, Air, Burner %, Burner SV) beside the live chart, and whether each gets +/- step buttons.

History

How many roasts load per page, and the most you can compare at once.

Webhooks

Send an outbound HTTP POST to a URL of your own (ntfy, a Discord/Slack incoming webhook, Home Assistant, a script) on roast milestones, finish, or an emergency stop. Add any number, each with its own name, URL, and subscribed events — "Send test" checks a URL before you save it. See Architecture → Webhooks for the full event list and payload shape.

Device plugins

Only appears once at least one third-party protocol plugin is both installed and marked ready by its own author (see Architecture → Device plugins — the shipped example isn't, on purpose, so a fresh install normally shows nothing here at all). A checkbox per plugin hides or shows it on the New Roast form's "Plugin device" option, without deleting its file or restarting the server. Delete next to it is permanent instead — it removes the plugin and its file for good.

AI Roast Review (Ollama)

Point this at a local Ollama server to get AI-written reviews on a roast's own page (milestones, phase timing, rate-of-rise shape, control changes and notes -- never the raw per-second curve). Once a bean has five or more other finished roasts, the review also compares this roast's key numbers (duration, drop temperature, development time, development %, weight loss) to that bean's usual mean and spread, and is asked to call out anything that differs notably. The same Ollama setup also powers the Analysis page's own Ask the AI panel, a separate feature working on many roasts at once instead of just one.
