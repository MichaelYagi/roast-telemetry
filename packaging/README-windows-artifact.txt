Roast Telemetry for Windows
============================

This is an unsigned build (no paid Windows code-signing certificate) --
Windows will warn about it the first time you run it. That's expected,
not a sign anything's wrong.

To run it:

  1. Double-click "Roast Telemetry.exe".
  2. Windows shows "Windows protected your PC" (SmartScreen).
  3. Click "More info".
  4. Click "Run anyway".

After that first time, it opens normally like any other app.

Note: this approval is tied to this exact .exe, not to "Roast
Telemetry" as a name -- a future version will trigger the same warning
again the first time, even though it's the same app.
